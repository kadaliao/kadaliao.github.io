应用

macOS、iOS、Android、Linux 和浏览器里的独立应用

Open Super Agent

Python

可以自己部署的常驻 AI 队友：会聊天，会派活，还有一台能看、能接手的电脑。开源，可替代 Grok Bot，模型自选。

  • macOS 桌面 App
  • iPhone（内测）
  • Docker 部署
  • 飞书 / 钉钉 / 企业微信
  • MCP

brew install --cask kadaliao/tap/open-super-agent

开心果

GoSwiftKotlin

红果短剧的极简客户端：无广告、不烧心。三个平台都是原生写的，Mac 版用 Go 直接在 GPU 上画界面，安装包约 8 MB。

  • macOS
  • iPhone / iPad
  • Android

观看记录和收藏只存在本机 · 华为手机也能装

sessift

Rust

在本机和其他机器上一起搜索、浏览、恢复 AI 编程助手的会话。数据不同步，查询时 SSH 过去现场查，只把结果传回来。

  • Claude Code
  • Codex
  • Pi
  • OpenCode
  • Grok

brew install kadaliao/tap/sessift

SuckMyDisk

Swift

给 macOS 26 的磁盘空间工具。认得出项目、渲染帧、开发缓存和本地模型，告诉你哪些能放心删、删了实际能腾出多少、怎么找回来。

  • 只在本地
  • 实时索引
  • smd 命令行
  • 中文 / English

APFS 克隆和硬链接只算一次 · iCloud、.git 永远不碰

Tizi

Go

基于 Mihomo 的代理工具。填好机场订阅点「连接」：国内网站直连，海外网站走代理，不用自己写规则。

  • macOS 桌面版
  • 终端版
  • Ubuntu
  • 内网 OpenVPN
  • Tailscale
  • Claude 线路保护

brew install --cask kadaliao/tap/tizi-desktop

Chezmate

Rust

chezmoi 的桌面伴侣，让几台电脑上的配置文件保持一致。每个文件只有一种状态，一个「同步」按钮；命令行输出 JSON，自带 MCP 服务。

  • GPUI
  • CLI + MCP
  • 自带 chezmoi
  • 中文 / English

所有操作都调用你机器上真实的 chezmoi 和 git

QuickEdit

Go

极致快速的轻量编辑器：看代码、改配置、读 Markdown、翻日志，打开就用，用完就走。原生 GPU 绘制，应用 12 MB；打开 10.8 万行的 Go 文件，冷启动 0.5 秒，开着窗口时 68 毫秒。

  • Markdown 并排预览
  • 30 多种语言高亮
  • 标签页
  • qe 命令行

brew install --cask kadaliao/tap/quickedit
