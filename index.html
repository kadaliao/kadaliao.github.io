关于

我是 Python 工程师，在北京。项目基本都从一个小不方便开始：会话散在三台机器上翻不到，就写 sessift；想知道模型每秒吐多少 token，就改 Claude Code 的 statusline。

不太做 demo，做出来自己不用，就放下了。只在自己会碰到的地方抠细节：sessift 只读不写，索引放 ~/.sessift，因为它不该碰别人的数据；ccenv 只给离散等级、不打综合分，因为一个分数会让人以为问题解决了。

更新不快，经常一个项目放几周再捡起来。GitHub 上有句 Better late than never，算是给自己的。
